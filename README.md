
# Squad page

Squad page voor FDND.  
Een one-pager die de squad voorstelt, doorlinkt naar ieders visitekaartje en campusplekken rond de Amstelcampus laat zien.

Beschrijving

Dit is de squad page van **A.M.S**, *Your Tribe*.

De pagina bestaat uit drie onderdelen:

1. **Hero** — titel, en een ingang naar de rest van de pagina  
2. **Work / Constellations** — squadleden als een sterrenbeeld. Hover of tik op een naam om hun kaart te zien en hun profielsite te openen  
3. **Spots** — oneindige carousel met HvA- / Amstelcampus-plekken. Klik op een foto voor meer informatie  

De uitstraling is bordeaux, paars en blauw.


Gebruik

Open de live site.

- **Nav** — spring naar Home, Work of Spots  
- **Constellation** — kies een squadlid om het visitekaartje te openen  
- **Spots** — laat de carousel lopen, of klik op een locatie voor extra info  

Geen login. Het is een statische HTML-, CSS- en JavaScript-site.


Kenmerken

Technieken

- HTML
- CSS (opgesplitst per onderdeel)
- Vanilla JavaScript
- CSS Grid en Flexbox
- IntersectionObserver voor scroll-reveals
- Oneindige image-carousel
- prefers-reduced-motion
